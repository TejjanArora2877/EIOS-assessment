# EIOS MVP — Clean React + FastAPI RAG Grading System

EIOS (Educational Intelligent Objective Scoring) is a local, single-user educational grading application built according to the architecture specification in `docs/rag_architecture.png`.

## Core Capabilities

1. **Institutional Knowledge Base**: Upload textbooks, lecture notes, and reference books (PDF, DOCX, TXT) with automatic PII redaction, logical chunking, and dual-index retrieval (ChromaDB dense vectors + BM25 lexical).
2. **Assessments & Rubrics**: Create and manage questions, authoritative model answers, teacher-defined rubric criteria, and reference scopes stored persistently in SQLite.
3. **Hybrid RAG Pipeline**: Combines dense semantic retrieval and BM25 lexical retrieval using Reciprocal Rank Fusion (RRF), followed by Cross-Encoder reranking (`ms-marco-MiniLM-L-6-v2`) to surface genuine institutional evidence.
4. **Deterministic Grading Engine**: Criterion-by-criterion semantic evaluation, contradiction detection (`nli-deberta-v3-small`), concept coverage against reference evidence, response quality analysis, and UCE (Understanding, Clarity, Expression) cognitive evaluation.
5. **Constructive Local Feedback**: Explanations generated by local Ollama (`llama3.2`) without altering numerical marks.
6. **Provenance & Traceability**: Cites verified document names, page numbers, and snippets, with automatic teacher-review flags when evidence is insufficient.

## Setup & Startup Instructions

### 1. Prerequisites
- Python 3.10+
- Node.js 18+ and npm
- Ollama installed locally with `llama3.2` model (`ollama run llama3.2`)

### 2. Backend Setup
```bash
# Install Python dependencies
pip install -r requirements.txt

# Start the FastAPI backend (runs on 127.0.0.1:8000)
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload
```

### 3. Frontend Setup
```bash
# Navigate to frontend directory
cd frontend

# Install npm packages
npm install

# Start Vite dev server (runs on 127.0.0.1:5173)
npm run dev
```

### 4. Running Tests
```bash
# Run pytest test suite
pytest
```
